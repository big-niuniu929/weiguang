# 质量检查清单

定稿前逐项打勾，任何一项不过就回到对应步骤。

## 主体

- [ ] 原告信息与身份证件一致（姓名、性别、出生日期、身份证号、住址、电话）
- [ ] 被告是公司时：全称、统一社会信用代码、住所地、法定代表人都与公示信息一致，且**截图留存**
- [ ] 被告是个人时：姓名 + 身份证号/户籍地，来源写清楚

## 诉求

- [ ] 每条诉求只提一件事，能执行（给钱、给物、做/不做某行为）
- [ ] 金额与证据能对上；大小写一致
- [ ] 利息/违约金的计算方式写明起点、标准、止点
- [ ] 诉讼费承担写了
- [ ] 诉求之间不矛盾

## 事实与理由

- [ ] 按时间顺序，一段一个事实
- [ ] 每个数字后面能指回证据编号
- [ ] 没有推断、没有形容词式的评价（「恶意」「欺骗」这类词要有事实支撑，否则删）
- [ ] 法律依据只引与事实直接相关的条文

## 证据

- [ ] 证据清单的编号与附件文件名一一对应
- [ ] 每条只写一个证明目的
- [ ] 电子证据注明了来源与形成方式（微信/银行/平台）
- [ ] 页数与实际一致

## 形式

- [ ] 管辖法院正确（被告住所地 / 合同履行地）
- [ ] 份数：法院一份 + 被告人数份
- [ ] 签名处手写签名，日期填实际提交日
- [ ] 送达地址与联系方式填写完整
