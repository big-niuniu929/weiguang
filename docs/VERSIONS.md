# 版本线

这个仓库不是代码库，只有一条内容线；改动按「结构调整」与「案由补充」分开记。

| 时间 | 变更 | 原因 |
|---|---|---|
| 2025.07 | 起手：4 类文书骨架（民事起诉状 / 证据清单 / 协助调查申请书 / 情况说明） | 实际交付里反复用到的就是这四类 |
| 2025.09 | 案由扩到 9 类，每类加「要素表 + 必备证据」 | 咨询里出现的纠纷类型比预想集中：借贷、消费预付、租赁占了大半 |
| 2025.11 | 五阶流程 SOP 成形，提示词按层拆开 | 出错多数不是「模型写得不好」，是「喂进去的要素错了」，所以把错误挡在起草之前 |
| 2026.01 | 案由扩到 15 类，加「常见抗辩 + 管辖提示」 | 抗辩和管辖是最常见的两处翻车点 |
| 2026.03 | 加脱敏规范与质量检查清单 | 模板外流时最容易带出真实信息；检查清单把「校对」这一步固定下来 |
| 2026.05 | 通用骨架补「情况说明书」「协助调查申请书」的变体 | 主体信息不全的案子，往往要先解决「对方是谁」 |
