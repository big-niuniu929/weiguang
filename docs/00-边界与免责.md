# 边界与免责

这个仓库的用途是**降低文书写作的门槛**，不是替代判断。

## 明确不做的事

| 不做 | 原因 |
|---|---|
| 不代理、不出庭 | 没有专业身份，也不以任何专业身份出现 |
| 不签收法院文书 | 送达是当事人与法院之间的事 |
| 不承诺结果 | 结果由事实、证据和法院判断决定，任何人承诺都不可信 |
| 不提供法律意见 | 这里只有结构和写法，没有「你这个案子该不该打」的结论 |
| 不接商业委托、不收费 | 公益性质；不设收费，也不接受商业委托 |
| 不经手当事人之间的钱 | 钱只在当事人与对方之间走 |

## 三条硬约束

1. **事实由当事人提供**：模板里的每一处空白都由当事人回答；模型不替他编
2. **数字必须可追溯**：每个金额、日期、账号都要能指回一份原始材料
3. **署名与提交都是当事人本人**：文书以本人名义提交，提交动作由本人完成

## 适用与不适用

**适合**：小额、事实清楚、证据在自己手上、不需要鉴定评估的纠纷（借贷、消费预付、租赁、平台交易、服务违约等）。

**不适合**：需要鉴定评估的（人身损害、工程质量）、证据链缺失的、涉及刑事的、法律关系复杂的。这类应当找专业机构，模板帮不上忙，硬套反而有害。
