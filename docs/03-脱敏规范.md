# 脱敏规范

这个仓库里**不允许**出现任何真实案件信息。以下是复核用的检查项。

## 必须替换

| 类型 | 处理 |
|---|---|
| 自然人姓名 | `【原告姓名】`、`【被告姓名】`；示例中用「甲」「乙」或虚构名 |
| 身份证号 | 只保留格式说明：`【18 位身份证号】` |
| 手机号 / 微信号 / 银行卡号 | `【联系电话】`、`【微信号】`、`【收款账号】` |
| 公司名称 | `【被告公司全称】`；示例中用「某某健身服务有限公司」这类明显虚构名 |
| 统一社会信用代码 | `【18 位统一社会信用代码】` |
| 法院名称 | `【有管辖权的基层人民法院】` |
| 金额 | 模板里写 `【金额】元`；示例里用整数虚构金额 |
| 具体地址 / 门牌号 | 只到「市 + 区」，不写门牌 |
| 证据截图 | 一律不入库；只保留文字描述与页数 |

## 反向检查

提交前在这个目录里搜一遍，命中任意一项就要处理：

```
身份证号格式：  \d{17}[\dXx]
手机号格式：    1[3-9]\d{9}
统一社会信用代码： [0-9A-Z]{18}
真实公司后缀 + 具体名称： 有限公司 / 有限责任公司 + 非虚构名
法院全称：      .{2,10}(人民法院)
```

## 示例数据的规矩

示例必须是**虚构**的，并且一眼能看出是虚构：人名用「甲/乙」，公司名带「某某」，金额取整数，地址只写市区。

示例的作用是演示「填进去长什么样」，不是提供可直接改改就交的成品。
