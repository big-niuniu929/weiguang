# 分层提示词工作流

提示词只做一件事：**把要素填进结构**。判断不交给模型。

## 为什么分层

一份文书出问题，通常不是「模型写得不好」，而是「喂给它的要素是错的」。分层的目的是让错误**在进入文书之前**被看见。

| 层 | 输入 | 输出 | 谁负责 |
|---|---|---|---|
| L1 问诊 | 当事人叙述 | 五要素表（谁/什么事/有什么/要什么/在哪） | 人问，模型只做结构化 |
| L2 归集 | 材料清单 | 证据表 + 时间线 + 诉求 | 人核对，模型只做归类 |
| L3 起草 | L1 + L2 + 案由模板 | 初稿 | 模型按结构填，不许新增事实 |
| L4 校对 | 初稿 + 原始材料 | 差异清单 | 人逐段核 |
| L5 指引 | 定稿 | 提交操作步骤 | 人写 |

## L1 问诊提示词

```
我在整理一件民事纠纷的材料，请把下面的叙述整理成五要素表，不要推断、不要补充我没有说的内容，
缺失的项写「待补充」：
1. 当事人（原告/被告，个人或公司，已知信息）
2. 争议事实（按时间顺序，只说事情）
3. 手上材料（逐项列出）
4. 诉求（要对方做什么）
5. 管辖线索（合同履行地/被告住所地）
叙述：<粘贴>
```

## L2 归集提示词

```
下面是我的材料清单和事情经过。请整理成两张表：
A. 证据表：编号 / 名称 / 来源 / 页数 / 证明目的（每条只证明一个事实）
B. 时间线：日期 / 发生了什么 / 对应证据编号
规则：材料里没有的事实不要写；无法对应证据的时间线条目标记「缺证据」。
```

## L3 起草提示词

```
按给定结构起草，严格遵守：
1. 只用我提供的要素，不许新增事实、数字、日期
2. 每个数字后面用【证据n】标注来源
3. 诉讼请求逐条写，每条只提一件事，金额写清币种与大写
4. 事实与理由按时间顺序，一段一个事实
5. 空着的项保留占位符，不要猜
结构：<粘贴模板>
要素：<粘贴 L1+L2 结果>
```

## L4 校对（人工，不用提示词）

逐段问四个问题：这句话的事实来自哪份材料？数字对不对？时间顺序对不对？被告主体名称和公示信息一致吗？

## L5 提交指引

写步骤，不写承诺。每一步都只说「点哪里、填什么、注意什么」，不写「应该会通过」。
