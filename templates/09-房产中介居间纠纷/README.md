# 案由：房产中介居间纠纷

中介费不退、隐瞒房屋瑕疵、跳单争议、押金与租金经手不清。核心是「中介是否尽到如实报告义务」。

## 要素表

| 要素 | 要问清什么 |
|---|---|
| 居间关系 | 谁委托、委托内容、中介费标准与支付节点 |
| 房屋情况 | 签约时中介告知了哪些、隐瞒了哪些 |
| 现场情况 | 签约现场有谁、说过什么、有没有书面记录 |
| 损失 | 中介费、押金、维修费、其他直接损失 |
| 主体 | 中介公司全称、门店、经办人 |

## 必备证据

- 居间合同/看房确认书
- 中介费支付凭证
- 房屋现状照片、渗水/损坏证据
- 与中介的沟通记录
- 居间方情况说明书（经办人出具）

## 诉讼请求写法

- 判令被告返还中介费【金额】元
- 判令被告赔偿损失【金额】元
- 判令被告承担诉讼费用

## 常见抗辩与应对

- 「已促成签约」→ 促成签约不等于免除如实报告义务
- 「房屋状况你自己看过」→ 隐蔽瑕疵（渗水、结构改动）看房时无法发现
- 「经办人个人行为」→ 职务行为由公司承担

## 管辖

被告住所地或居间行为发生地基层人民法院。

## 提示

让经办人出具「情况说明书」固定签约现场的口头约定，比事后各说各话有力得多。
