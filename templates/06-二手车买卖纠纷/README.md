# 案由：二手车买卖纠纷

调表、事故车隐瞒、过户拖延、质量故障。核心是「卖方是否隐瞒重大瑕疵」以及「是否构成欺诈」。

## 要素表

| 要素 | 要问清什么 |
|---|---|
| 交易 | 车价、时间、平台/车商/个人、有没有检测报告 |
| 车况陈述 | 卖方对里程、事故、泡水、火烧的承诺写在哪 |
| 发现问题 | 什么时候发现、怎么发现、第三方检测结论 |
| 过户 | 有没有过户、卡在哪一步 |
| 主体 | 卖方是个人、车商还是平台 |

## 必备证据

- 买卖合同、转让协议
- 付款凭证
- 第三方检测报告（4S 店/检测机构）
- 卖方对车况的承诺（广告页、聊天记录、合同条款）
- 维修记录、保险出险记录

## 诉讼请求写法

- 判令撤销/解除买卖合同，返还购车款【金额】元并退还车辆
- 判令被告赔偿检测费、维修费、交通费【金额】元
- 判令被告承担诉讼费用

## 常见抗辩与应对

- 「二手车本来就有磨损」→ 用「调表」「重大事故未告知」区分正常磨损与重大瑕疵
- 「你验过车了」→ 验车不等于放弃对隐瞒事实的追责
- 「价格已经让了」→ 让价不代表同意接受隐瞒的瑕疵

## 管辖

被告住所地或合同履行地基层人民法院。

## 提示

主张欺诈可要求惩罚性赔偿，但举证门槛高：需要证明卖方「明知且故意隐瞒」。
