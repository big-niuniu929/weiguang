# 案由：消费预付纠纷

健身卡、美容卡、培训课这类「先付钱后消费」的合同。核心争点是「剩余价值怎么算」和「过期作废条款是否有效」。

## 要素表

| 要素 | 要问清什么 |
|---|---|
| 合同成立 | 什么时候买的、买了什么、多少钱、有没有书面合同 |
| 履行情况 | 消费了多少次、剩余多少、有没有停业/迁址 |
| 拒绝退款的理由 | 对方说的是「过期」「不退不换」还是「已提供服务」 |
| 格式条款 | 合同/卡面/小程序里有没有「概不退款」「过期作废」这类条款 |
| 主体 | 收款方是门店、加盟商还是品牌方；营业执照上的主体是谁 |

## 必备证据

- 付款凭证（微信/支付宝/银行卡）
- 会员卡、合同、订单截图、小程序页面
- 剩余次数/余额的证明（系统截图、教练确认记录）
- 对方拒绝退款的沟通记录
- 经营主体公示信息（国家企业信用信息公示系统）

## 诉讼请求写法

- 判令解除双方于【日期】成立的服务合同
- 判令被告返还未消费部分款项【金额】元
- 判令被告支付资金占用利息（自起诉之日起按 LPR）
- 判令被告承担诉讼费用

## 常见抗辩与应对

- 「卡已过期」→ 过期作废属于排除消费者主要权利的格式条款，可主张无效
- 「已消费完」→ 要求对方提供消费记录，逐笔核对
- 「去找加盟商」→ 核对收款主体与合同相对方，锁定适格被告

## 管辖

被告住所地或合同履行地基层人民法院（服务提供地通常即为履行地）。

## 提示

预付卡类纠纷金额通常不大，立案前先算清「未消费部分」的计算口径，写进诉状。
