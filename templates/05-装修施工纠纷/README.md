# 案由：装修施工纠纷

工期拖延、偷工减料、增项加价、尾款争议。核心是「工程量与质量标准」的举证，通常需要第三方评估。

## 要素表

| 要素 | 要问清什么 |
|---|---|
| 合同 | 总价、工期、付款节点、材料清单、验收标准 |
| 履行 | 已付多少、做到哪一步、工期延误多久 |
| 质量问题 | 具体是哪几处、有没有照片/视频、有没有第三方检测 |
| 增项 | 增项是否书面确认、有没有签字 |
| 主体 | 签约方是装修公司还是个人工长 |

## 必备证据

- 装修合同、报价单、材料清单
- 付款凭证与收据
- 施工过程照片、视频、验收记录
- 质量问题清单与沟通记录
- 第三方检测/评估报告（如有）

## 诉讼请求写法

- 判令被告继续履行/完成剩余工程
- 判令被告赔偿返工费用【金额】元
- 判令被告支付逾期违约金【金额】元
- 判令被告承担诉讼费用

## 常见抗辩与应对

- 「增项是口头同意的」→ 要求出示书面确认或微信确认记录
- 「质量没问题」→ 有检测报告最直接；没有则申请法院委托鉴定
- 「已经完工」→ 用验收单与现场照片反驳

## 管辖

被告住所地或合同履行地（施工地）基层人民法院。

## 提示

金额较大或质量争议复杂时，鉴定费用可能超过标的额，先算清楚再决定是否起诉。
