# 案由：婚恋中介服务纠纷

交了几万块会员费，介绍的对象与承诺不符、服务缩水、退费被拒。核心是「服务是否达到约定标准」。

## 要素表

| 要素 | 要问清什么 |
|---|---|
| 合同 | 服务期限、介绍人数、承诺的对象条件、价格 |
| 实际服务 | 介绍了几位、见了几次、是否符合约定条件 |
| 虚假承诺 | 对方承诺了什么（学历/职业/收入），实际是什么 |
| 退费沟通 | 什么时候提出、对方怎么答 |
| 主体 | 签约公司、收款公司、门店是否同一主体 |

## 必备证据

- 服务合同与附件（承诺清单）
- 付款凭证、发票
- 介绍记录（名单、见面次数）
- 销售承诺的聊天记录/录音
- 退费申请与回复

## 诉讼请求写法

- 判令解除婚介服务合同
- 判令被告退还服务费【金额】元
- 判令被告承担诉讼费用

## 常见抗辩与应对

- 「已提供服务」→ 用约定人数/条件与实际记录逐项对照
- 「合同写了不退」→ 该类格式条款可主张无效或按未履行部分返还
- 「销售个人承诺不代表公司」→ 销售在职务范围内的承诺对公司有约束力

## 管辖

被告住所地或服务提供地基层人民法院。

## 提示

这类纠纷的关键证据是「销售当时怎么说的」：聊天记录、录音务必保全原始载体。
