# 案由：服务合同违约纠纷

摄影、设计、插画、短剧、代运营这类「看不见成果」的服务：交付延期、反复修改、成品不合约定、尾款争议。核心是「约定成果」怎么界定。

## 要素表

| 要素 | 要问清什么 |
|---|---|
| 合同 | 服务内容、交付标准、期限、价格、修改次数 |
| 履行 | 做到哪一步、交付了什么、对方确认了没有 |
| 违约点 | 延期多久、哪里不符合约定、修改了几轮 |
| 沟通 | 催过几次、对方怎么答 |
| 损失 | 已付款、返工成本、机会损失 |

## 必备证据

- 服务合同/订单/报价单（含交付标准）
- 付款凭证
- 交付物与版本记录（含时间戳）
- 沟通记录（需求确认、修改意见、催告）
- 对方违约的证明（延期通知、拒绝交付）

## 诉讼请求写法

- 判令解除服务合同
- 判令被告返还已付款【金额】元
- 判令被告支付违约金【金额】元
- 判令被告承担诉讼费用

## 常见抗辩与应对

- 「需求一直在改」→ 用合同约定的修改次数反驳
- 「已经交付了」→ 交付物是否符合约定标准，逐项对照
- 「创意服务没有标准」→ 合同里的验收条款就是标准

## 管辖

被告住所地或服务履行地基层人民法院。

## 提示

这类纠纷胜负常取决于「交付标准写没写清」；写清了是违约，没写清是扯皮。
