# 案由：兼职接单与劳务报酬纠纷

线上接单（代练、设计、剪辑、跑腿）做完不给钱，或平台扣款。核心是「工作量确认」与「相对方身份」。

## 要素表

| 要素 | 要问清什么 |
|---|---|
| 约定 | 在哪接的单、单价、工作量、结算方式、谁派的单 |
| 交付 | 交付了什么、什么时候交的、对方有没有确认 |
| 欠款 | 应结多少、已结多少、欠多少 |
| 相对方 | 是个人、工作室还是公司；收款方是谁 |
| 证据 | 聊天记录、交付记录、平台订单 |

## 必备证据

- 接单聊天记录（含报价与确认）
- 交付物与交付时间记录
- 结算记录（已付部分）
- 平台订单/工单截图
- 对方身份线索（微信号、手机号、公司名）

## 诉讼请求写法

- 判令被告支付劳务报酬【金额】元
- 判令被告支付逾期付款利息
- 判令被告承担诉讼费用

## 常见抗辩与应对

- 「质量不合格」→ 要求对方在交付时提出，事后提出需要有依据
- 「已经结清」→ 核对每笔转账与对应工单
- 「找我老板」→ 核对派单主体与收款主体

## 管辖

被告住所地或劳务履行地基层人民法院。

## 提示

接单类纠纷金额小、对方身份模糊，先把「谁欠钱」确定下来，再谈金额。
