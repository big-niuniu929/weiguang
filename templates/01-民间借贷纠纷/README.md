# 案由：民间借贷纠纷

最常见也最容易打好的一类：事实单一（借钱、没还），证据集中（转账 + 催告）。难点在「借贷合意」的证明和利息口径。

## 要素表

| 要素 | 要问清什么 |
|---|---|
| 借款合意 | 什么时候、怎么说的、借多少、什么时候还；有借条/聊天记录吗 |
| 交付方式 | 转账还是现金；转账是谁的账户转给谁的账户 |
| 已还多少 | 有没有部分还款，还的是本金还是利息 |
| 利息约定 | 有没有约定利息/逾期利息；年化多少；超过 LPR 四倍的部分不受保护 |
| 催告情况 | 什么时候催的、怎么催的、对方怎么回 |

## 必备证据

- 转账凭证（银行流水 / 微信支付电子凭证，需体现双方账号）
- 借条或聊天记录中的借款与还款承诺
- 催告记录（微信 / 短信 / 通话录音）
- 部分还款记录（如有）

## 诉讼请求写法

- 判令被告偿还借款本金【金额】元
- 判令被告支付自【逾期日】起按【LPR / 约定利率】计算的利息至实际清偿日
- 判令被告承担诉讼费用

## 常见抗辩与应对

- 「不是借款，是赠与/投资款」→ 用聊天记录里的还款承诺、利息约定反驳
- 「已经还了」→ 要求对方举证，核对转账时间与金额
- 「超过诉讼时效」→ 用催告记录证明时效中断

## 管辖

被告住所地或合同履行地（接收货币一方所在地）基层人民法院。

## 提示

现金交付的借贷，交付事实最难证明；没有其他佐证时，先补证据再起诉。
