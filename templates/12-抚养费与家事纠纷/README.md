# 案由：抚养费与家事纠纷

抚养费拖欠、变更抚养关系、离婚后财产分割遗留问题。涉及身份关系，程序要求更严。

## 要素表

| 要素 | 要问清什么 |
|---|---|
| 身份关系 | 结婚/离婚时间、子女情况、离婚协议或判决内容 |
| 约定内容 | 抚养费标准、支付方式、支付期限 |
| 履行情况 | 付了多少、欠了多少、催过几次 |
| 收入情况 | 对方收入水平（用于主张调整） |
| 子女现状 | 实际抚养人、生活教育支出 |

## 必备证据

- 离婚证/判决书/调解书
- 离婚协议中关于抚养费的条款
- 转账记录（已付部分）
- 催告记录
- 子女生活教育支出凭证

## 诉讼请求写法

- 判令被告支付拖欠的抚养费【金额】元
- 判令被告自【日期】起按每月【金额】元支付抚养费
- 判令被告承担诉讼费用

## 常见抗辩与应对

- 「没有钱」→ 收入情况可申请法院调查
- 「孩子不让我看」→ 探望权与抚养费是两个法律关系，不能互相抵销
- 「协议约定过一次付清」→ 按协议主张，注意诉讼时效

## 管辖

被告住所地基层人民法院；涉及不动产分割的由不动产所在地法院管辖。

## 提示

身份关系案件材料要求严，证件不全时先补齐再立案。
