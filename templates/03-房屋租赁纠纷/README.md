# 案由：房屋租赁纠纷

押金不退、提前退租、房屋质量、转租纠纷。核心是「谁违约」和「押金该不该扣、扣多少」。

## 要素表

| 要素 | 要问清什么 |
|---|---|
| 租赁关系 | 租期、租金、押金、支付方式；合同是谁签的（本人/中介/二房东） |
| 房屋状况 | 入住时有没有拍照；损坏是原有还是后来造成 |
| 退租经过 | 什么时候提出退租、怎么交接、钥匙有没有还 |
| 押金扣留理由 | 对方说扣什么费用、有没有单据 |
| 相对方 | 出租人是房东、二房东还是中介公司；居间方是谁 |

## 必备证据

- 租赁合同 / 电子签约记录
- 押金与租金支付凭证
- 房屋交接照片、视频（入住时与退租时）
- 退租沟通记录、交接单
- 居间方情况说明（如经中介成交）

## 诉讼请求写法

- 判令被告返还押金【金额】元
- 判令被告返还多收租金/赔偿损失【金额】元
- 判令被告承担诉讼费用

## 常见抗辩与应对

- 「房屋有损坏」→ 要求对方提供维修单据与损坏时点证据
- 「你违约在先」→ 核对合同解除条款与实际通知时间
- 「我不是房东」→ 查明实际出租主体，二房东需追加房东或另案

## 管辖

被告住所地或租赁房屋所在地基层人民法院（不动产纠纷由不动产所在地专属管辖）。

## 提示

押金纠纷常伴随「居间方情况说明」，把签约现场的口头约定固定下来很关键。
