# 案由：平台账号封禁纠纷

账号被限流、封禁、扣保证金、冻结收益。核心是「平台规则有没有被违反」以及「处罚是否与规则一致」。

## 要素表

| 要素 | 要问清什么 |
|---|---|
| 账号 | 平台、账号 ID、注册时间、实名主体 |
| 处罚 | 什么时间、什么理由、处罚形式（限流/封禁/扣款） |
| 规则 | 平台援引了哪条规则、你知不知道这条规则 |
| 申诉 | 申诉过几次、结果如何 |
| 损失 | 账号内余额、可预期收益、投入成本 |

## 必备证据

- 账号主页与处罚通知截图
- 平台规则原文（含版本与生效时间）
- 申诉记录与平台回复
- 收益/余额证明
- 实名认证信息

## 诉讼请求写法

- 判令被告恢复账号正常使用/解除封禁
- 判令被告返还账户余额/收益【金额】元
- 判令被告赔偿损失【金额】元
- 判令被告承担诉讼费用

## 常见抗辩与应对

- 「违反用户协议」→ 要求平台举证具体违反了哪一条、证据是什么
- 「规则解释权归平台」→ 格式条款不能排除用户主要权利
- 「账号不是你的」→ 实名信息与注册信息是权属证据

## 管辖

被告住所地（平台运营主体所在地）或合同履行地基层人民法院。

## 提示

这类案件往往涉及平台格式条款的效力，先看规则原文与处罚通知是否对得上，再决定是否起诉。
