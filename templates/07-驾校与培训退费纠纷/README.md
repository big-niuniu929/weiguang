# 案由：驾校与培训退费纠纷

报名后拖延、无法约考、承诺不兑现、退费被扣高额违约金。核心是「谁的原因导致无法继续」。

## 要素表

| 要素 | 要问清什么 |
|---|---|
| 报名 | 时间、班型、总价、承诺内容（多久拿证/包过） |
| 履行 | 考到哪一科、约考失败几次、驾校/机构做了什么 |
| 拖延证据 | 约考记录、教练沟通、排期通知 |
| 退费主张 | 已消费部分怎么算、对方要扣多少、依据是什么 |
| 主体 | 合同主体是驾校、挂靠队还是招生中介 |

## 必备证据

- 报名合同、收据、付款凭证
- 约考记录截图、排期通知
- 与教练/客服的沟通记录
- 承诺内容的截图（「三个月拿证」这类）
- 经营主体公示信息

## 诉讼请求写法

- 判令解除培训服务合同
- 判令被告退还培训费【金额】元
- 判令被告支付利息/违约金【金额】元
- 判令被告承担诉讼费用

## 常见抗辩与应对

- 「已提供服务」→ 按实际进度折算，要求对方提供课时/进度记录
- 「违约金照合同扣」→ 违约金过高可请求调整
- 「找招生的人」→ 核对收款主体，招生中介与驾校可能承担连带责任

## 管辖

被告住所地或培训服务提供地基层人民法院。

## 提示

「包过」「保过」这类承诺本身不合规，可作为对方虚假宣传的证据使用。
