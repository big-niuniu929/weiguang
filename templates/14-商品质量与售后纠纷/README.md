# 案由：商品质量与售后纠纷

买到的商品有质量问题、商家拒绝退换修、承诺的保修不履行。核心是「质量问题的时点」与「是否属于三包范围」。

## 要素表

| 要素 | 要问清什么 |
|---|---|
| 购买 | 平台/门店、商品、价格、时间、发票 |
| 问题 | 什么故障、什么时候出现、有没有维修过 |
| 沟通 | 找过商家/平台/厂家几次、答复是什么 |
| 承诺 | 商品页/客服承诺的保修与售后条款 |
| 损失 | 维修费、误工、其他直接损失 |

## 必备证据

- 订单、发票、支付凭证
- 商品实物照片/视频、故障演示
- 商品页与客服承诺截图
- 售后沟通记录与处理结果
- 维修单据/检测报告

## 诉讼请求写法

- 判令被告履行修理/更换/退货义务
- 判令被告退还货款【金额】元并赔偿损失
- 判令被告承担诉讼费用

## 常见抗辩与应对

- 「人为损坏」→ 要求对方出具检测结论，不能只口头认定
- 「超出保修期」→ 核对保修起算日与承诺内容
- 「找厂家」→ 销售者与生产者可择一主张

## 管辖

被告住所地或合同履行地（收货地）基层人民法院。

## 提示

质量争议常需要检测，检测成本可能高于标的额；金额小的优先走平台与消协渠道。
