# 案由：二手平台交易纠纷

闲鱼、转转这类平台上的买卖：货不对板、收款不发货、退款被拒。难点是「对方是谁」——平台账号背后的实名主体往往需要调查令。

## 要素表

| 要素 | 要问清什么 |
|---|---|
| 交易过程 | 平台、商品、价格、下单时间、支付方式 |
| 违约事实 | 发了什么、收到什么、与描述差在哪 |
| 平台介入结果 | 有没有申请平台仲裁、结论是什么 |
| 对方身份线索 | 昵称、实名认证姓名、手机号、发货地址 |
| 损失 | 货款、运费、鉴定费、其他直接损失 |

## 必备证据

- 订单截图、商品页面截图（含描述与承诺）
- 支付凭证与物流记录
- 收到货物的实物照片、开箱视频
- 与卖家的聊天记录
- 平台处理结果截图

## 诉讼请求写法

- 判令解除买卖合同并返还货款【金额】元
- 判令被告赔偿运费/损失【金额】元
- 判令被告承担诉讼费用

## 常见抗辩与应对

- 「二手商品不退不换」→ 若存在描述不符或隐瞒瑕疵，仍可主张违约
- 「我是代卖」→ 核对收款主体与发货主体
- 主体不明 → 先申请协助调查，调取账号实名信息

## 管辖

被告住所地或合同履行地（收货地）基层人民法院。

## 提示

平台主体信息不全时，先走「协助调查申请书」把被告确定下来，否则立案会被退。
