# 案由：网络名誉侵权纠纷

被网暴、被造谣、被挂人。核心是「言论是否失实」「是否指向特定人」「传播范围多大」。

## 要素表

| 要素 | 要问清什么 |
|---|---|
| 侵权内容 | 发在哪个平台、什么账号、什么时间、原文是什么 |
| 指向性 | 内容里有没有能识别到你的信息（姓名、照片、单位、特征） |
| 失实 | 哪几句是假的、真实情况是什么、有没有证据 |
| 传播 | 阅读量、转发量、评论量、有没有被搬运 |
| 后果 | 有没有导致实际损失（工作、就医、社交） |

## 必备证据

- 侵权内容的完整截图 + 网页存档（含 URL、时间、账号）
- 能证明内容失实的材料
- 传播数据截图
- 要求删除/道歉的记录与对方回应
- 损失证明（如有）

## 诉讼请求写法

- 判令被告删除侵权内容、停止侵害
- 判令被告在【平台/公开媒体】赔礼道歉、消除影响
- 判令被告赔偿精神损害抚慰金【金额】元及维权合理支出
- 判令被告承担诉讼费用

## 常见抗辩与应对

- 「说的是事实」→ 事实陈述需真实；即使是事实，涉及隐私的公开也可能侵权
- 「没有指名道姓」→ 结合上下文可识别到特定人即构成指向
- 「已删除」→ 删除不免除已经造成的损害赔偿责任

## 管辖

侵权行为地（含被侵权人住所地）或被告住所地基层人民法院。

## 提示

截图必须保全原始载体（账号主页、发布时间、URL），只截内容不截账号，证明力会大打折扣。
