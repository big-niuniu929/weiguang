# 文书类型：和解协议 / 调解协议

| 项 | 内容 |
|---|---|
| 类型 | 结案文书（诉前 / 诉中均可） |
| 形式 | 双方私下签署（和解）或经法院主持（调解） |
| 效力 | 私下和解协议不具强制执行力；法院调解书与判决同等效力 |
| 建议 | 金额较大或分期履行时，优先选择法院调解书 |

## 关键条款（少一条都可能白签）

1. **义务要写清「谁、多少钱、什么时候、怎么付」**：写「近期归还」等于没写
2. **违约条款是核心**：没有加速到期条款，对方拖一期你只能再起诉一次
3. **一次性了结条款**：写明「本案争议一次性了结」，避免对方反复纠缠
4. **撤诉与付款挂钩**：先到账、再撤诉，顺序不要反
5. 想要强制执行力，就把协议内容做成**法院调解书**，别只签私下协议
