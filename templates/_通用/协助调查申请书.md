# 文书类型：协助调查申请书

| 项 | 内容 |
|---|---|
| 类型 | 程序性申请（起诉前 / 立案后均可提交） |
| 适用场景 | 只知道对方姓名 + 某个账号（微信 / 手机 / 平台 ID），不知道身份证号与住址，无法确定被告主体 |
| 提交渠道 | 向拟管辖法院立案窗口提交，或在立案后随卷提交 |
| 作用 | 请求法院向平台调取账号实名信息 |

---

# 协助调查申请书

申请人（原告）：【姓名】，【性别】，公民身份号码【18 位身份证号】，住址【住址】，联系电话【联系电话】

被申请人（被告）：【姓名 / 已知昵称】，【已知信息：微信号 / 手机号 / 平台账号】

## 请求事项

请求贵院依法向【平台公司全称，如：某某科技有限公司】调取账号【账号标识】的以下信息：

1. 该账号实名认证的完整姓名、身份证号码；
2. 该账号绑定的手机号码；
3. 该账号近【12】个月登录使用的 IP 地址及常用设备信息（用于辅助确定经常居住地）。

## 事实与理由

申请人诉【被告姓名】 【案由】一案，因【借款 / 交易 / 服务】发生争议，涉案金额【金额】元。

申请人仅掌握被告的【姓名 / 昵称】及账号【账号标识】，无法获得其身份证号码与准确住址，无法确定明确的被告、无法完成立案。该信息由平台独家掌握，申请人客观上无法自行获取。

依据《中华人民共和国民事诉讼法》关于当事人举证与人民法院调查取证的规定，以及《最高人民法院关于民事诉讼证据的若干规定》相关条文，申请贵院依法调取上述信息。

## 此致

【有管辖权的基层人民法院】

申请人（签名）：____________
【年】年【月】月【日】日

## 使用提示

- 立案前提交时，很多法院要求同时有**已提交的起诉材料**或明确的起诉意向说明
- 账号标识要写全（微信号/手机号/平台 ID），写错一位就调不到
- 平台公司全称要写工商登记全称，不要写产品名（产品名 ≠ 主体名）
- 调取结果通常回到法院，不会直接给申请人；后续按法院要求补充材料
