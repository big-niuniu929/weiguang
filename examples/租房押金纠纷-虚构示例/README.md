# 示例：租房押金纠纷（虚构）

> **完全虚构**。人名用「甲」「乙」，公司名带「某某」，金额取整数，法院写「某市某区人民法院」。
> 用途只有一个：演示「要素填进结构之后长什么样」。

## 案情（虚构）

乙向甲承租某市某区一处住宅，月租 3000 元，押金 3000 元。租期一年，乙按期退租并交还钥匙。
甲以「房屋有损坏」为由拒退押金，未提供任何维修单据。乙留存了入住与退租时的照片各 12 张。

## 填出来的样子

- `起诉状-示例.md`：诉讼请求只提押金一项，事实按时间顺序分三段
- `证据清单-示例.md`：5 条证据，一条一个证明目的

## 可以看到的几点

1. **诉讼请求只写能执行的事**：返还押金 + 利息 + 诉讼费，没有「赔礼道歉」这类与事实无关的诉求
2. **每个数字都指回证据**：「3000 元」在事实段后标了【证据2】
3. **被告主体写全称**：合同相对方是个人就写个人，是中介公司就写公司，不含糊
4. **管辖写清理由**：房屋所在地法院（不动产专属管辖）
